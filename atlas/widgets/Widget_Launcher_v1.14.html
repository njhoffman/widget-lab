How synchronization works
1
Choose your HTML source folder. Click Sync latest widgets and grant the browser access to the folder containing your widget HTML files.
2
Sync whenever you update a widget. The launcher scans subfolders, chooses each explorer's newest HTML file, compares its contents, and saves changed versions locally.
3
Optional: save real HTML copies. Choose an output folder. Future syncs write the current six widgets and their manifest.json into its launcher_widgets/ subfolder.
4
Use manual import as a fallback. On browsers without folder access, use Import artwork folder for complete extracted HTML and image assets, or Import HTML files for standalone editions.
