Prompt and design requirements

Generation prompt
AI-produced artwork is illustrative, not a scientifically dated reconstruction or a canonical depiction. The reference screenshot suggests composition, not facts. Approve scientific or cultural accuracy separately.

Review, licensing and approval

Acceptance criteria: artwork free of baked-in text, enough safe space for the atlas title, subject-specific composition, correct interval/figure symbolism, and documented usage rights.

Browser-local IndexedDB storage is best-effort; export your ZIP after reviewing.

Goal style direction

The generated atlas image is a layout/style benchmark, not an artwork reproduction source. Use dramatic depth, coherent atmospheric light, textured scenery, compact dark/cyan interface compatibility, and clean overlay space.

Artwork pack integration contract

The ZIP export contains imported images in replacements/ and a replacement_manifest.json mapping the original record ID to the new image. The integration step must validate source rights, recompute SHA-256, update the manifest, increment the atlas version, and regenerate the standalone HTML.
